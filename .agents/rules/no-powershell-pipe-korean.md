# 한글 인코딩 보호 규칙 (CRITICAL)

## 절대 금지 패턴

Windows PowerShell 환경에서 **한글이 포함된 코드를 파이프(`|`)로 Python에 전달하는 것을 절대 금지**한다.

```powershell
# ❌ 절대 금지 - 한글이 CP949로 깨져 ??? 로 치환됨
$python_script = @"
print("한글 텍스트")
"@
$python_script | python -
```

### 원인
Windows PowerShell은 파이프(`|`) 전달 시 시스템 기본 인코딩(CP949/ANSI)을 사용한다.
UTF-8 한글 바이트가 CP949로 강제 변환되며, 매핑 불가능한 문자는 `?`로 대체된다.
이로 인해 프론트엔드 UI, 문제 데이터, 주석 등의 한글이 `???`로 영구 파괴된다.

## 필수 준수 패턴

한글이 포함된 Python 코드를 실행해야 할 때는 반드시 다음 2단계를 따른다:

### 1단계: `write_to_file` 도구로 .py 파일 저장
```
write_to_file 도구를 사용하여 스크립트를 파일로 저장한다.
이 도구는 UTF-8 인코딩을 보장하므로 한글이 절대 깨지지 않는다.
```

### 2단계: `run_command`로 해당 파일을 직접 실행
```powershell
# ✅ 안전 - 파일에서 직접 읽으므로 UTF-8 유지
python script_name.py
```

## 한글이 없는 경우
한글이 전혀 포함되지 않은 순수 영문/코드만 있는 경우에는 인라인 실행도 허용한다.
단, 조금이라도 한글이 섞여 있으면 반드시 파일 저장 후 실행한다.

## 코드 수정 시 주의사항
- `replace_file_content` 도구를 통한 직접 편집은 UTF-8이 보장되므로 안전하다.
- 대규모 파일 덮어쓰기가 필요한 경우에도 `write_to_file`로 .py 스크립트를 저장한 뒤 실행하는 패턴을 사용한다.
- 수정 후에는 반드시 `???` 잔류 여부를 검증한다.
