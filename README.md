# HDAT-DA 실전 대비 데이터 분석 튜터팩

이 저장소는 HDAT-DA (데이터 분석) 인증 시험을 준비하기 위한 모든 핵심 자료를 담고 있습니다.

## 📂 파일 구성 가이드

복잡했던 이전 문서들을 모두 깔끔하게 통합하여 **2개의 핵심 파일**로 재설계했습니다.

1. **`MANUAL.md` (⭐️ 가장 중요)**
   - 시험장에 가져가야 할 **"7단계 만능 마스터 코드 (`universal_exam.py`)"**의 복사/붙여넣기용 원본이 들어있는 핵심 매뉴얼입니다.
   - 단일 데이터셋, 분할 데이터셋, 압축(ZIP) 파일 등 모든 돌발 상황에 대응하는 방법이 적혀있습니다.
   - **시험 직전 무조건 이 문서를 확인하세요.**

2. **`web_pandas_tutor.py` (웹 브라우저형 대화형 튜터)**
   - Pandas 기초 문법과 데이터 핸들링을 훈련할 수 있는 웹 기반 모의고사 튜터 앱입니다.
   - 실행 방법: 터미널에서 아래 명령어를 입력하세요.
     ```bash
     pip install streamlit
     streamlit run web_pandas_tutor.py
     ```

## 🛠️ 실전 모의고사 스크립트 실행법

실제 시험 문제(CSV/ZIP)가 들어있는 폴더를 대상으로 마스터 코드를 실행하려면 아래와 같이 실행합니다.

```bash
python universal_exam.py <데이터가_들어있는_폴더_경로>
```
*예시: `python universal_exam.py ../source/10996_Titanic`*

> **참고**: 더 이상 복잡한 설계 문서나 분산된 가이드는 필요 없습니다. 오직 `MANUAL.md`와 `universal_exam.py`에만 집중하세요! 성공적인 합격을 기원합니다. 🚀
